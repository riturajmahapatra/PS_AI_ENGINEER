# Project Shell

This project contains the basic directory shell structured for modular AI agent workflows and backend/frontend integrations.

## Directory Structure

- **`backend/`**: Core API backend server and business logic.
- **`frontend/`**: User interface and web client application.
- **`docker/`**: Container configurations, Dockerfiles, and Docker Compose scripts.
- **`db/`**: Database schemas, migration scripts, and seed data.
- **`agents/`**: AI Agent definitions, system prompts, and configuration files.
- **`runner/`**: Execution engine and task runner for agent orchestration.
- **`validators/`**: Input, output, and schema validation logic.
- **`logs/`**: Execution logs and audit trails.
- **`workflows/`**: Workflow definitions, pipeline DAGs, and task orchestration logic.
